# portfoliosync-test-listing

⚠️ **Repositório de teste. Não é um projeto de portfólio.**

Ele existe só para testar a listagem de repositórios da [PortfolioSync API](https://github.com/AlmeidaSNicolas/portfoliosync-api) (o `POST /admin/sync` e a busca por topic `portfolio`).

- Não tem código de aplicação.
- Não tem `portfolio.json`, então a sincronização deve registrar esse repositório como erro (é um caso de teste proposital).
- Pode ser apagado a qualquer momento, quando os testes da API não precisarem mais dele.
